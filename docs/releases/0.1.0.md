## 本次内容

- 多用户登录与权限、课程/课时检索、课程仓库标准、Git 同步、不可变发布、版本回退。
- API wheel 携带 Schema 和数据库迁移，`courseware-api server` 管理 API 与 Worker。
- 前端 npm 包携带静态资源及 `courseware-web server`，无需 Vite 或源码目录即可运行，提供同源代理及 `/version.json`。
- 根工作区以 submodule 固定四个独立仓库，通过 funbuild 统一发版。
- fundeploy 新增 courseware 服务声明；全新部署前端默认 8817，现有 8814/frpc 环境显式覆盖。

## 运行与回退

现有入口仍为 `http://8.130.133.114:18814`，frpc 转发至本机 8814，API 为 8008。运行代码来自已安装的发行包，配置保存在 `~/.farfarfun/courseware/`；原 PostgreSQL 和课程存储路径保持不变。API、Worker、前端由独立服务进程运行，不依赖开发终端。

切换前已停止写入，同批保存并检查 `.local/backups/20261107-110603-pre-0.1.0/` 下的 PostgreSQL dump、发布文件归档和私有配置。该目录不提交。此次迁移没有改变数据库版本；首版没有上一版正式包。如需回退，可先停止安装包服务，再恢复原开发启动入口；不要在 8814/8008 已占用时重复启动另一套服务。

Docker 路径和跨机生产环境未在本次执行；数据仍在原机器。fundeploy 的正式发布版尚未包含本 PR，本次启动验证使用接入分支编译的二进制。公网 HTTP 入口沿用明确开启的兼容配置，未升级为 HTTPS。
