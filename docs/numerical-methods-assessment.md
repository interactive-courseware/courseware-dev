## 1. 已确认的事实

- 课程首页 `web/index.html`，正式课时位于 `lessons/theory/*/web/` 与 `lessons/lab/*/web/`。
- 共 1 个课程首页、6 个理论课时、3 个上机课时，另有未发布模板。
- 首页提供 9 个教材章节；理论课、上机课和教材章节分别组织，L03 同时涉及第 3 章和第 5 章应用。
- 教师信息为刘琛、宁波大学、流体力学团队；具体课程制作人 author 身份仍需确认，不能只凭教师署名判断制作职责。
- 教学交互使用原生 JavaScript/Canvas、本地 KaTeX 与字体，未发现业务 fetch/XHR/WebSocket/API 调用。
- Python 服务继承标准库静态文件处理器，提供 Basic Auth、文件范围控制和静态发送；检查到的 GET/HEAD 路径没有教学计算 API。
- MATLAB 程序作为学习者下载内容，通过 `../matlab/*.m` 等相对路径引用，不由网页服务端执行。
- 对 10 个正式 HTML 页面检查了 144 处 href/src/poster 引用，未发现根绝对路径、外部 HTTP 依赖、缺失文件或越出仓库边界的引用。此检查不包含所有 CSS/JS 动态资源与完整浏览器运行结果。

结论：现有课程适合按静态文件发布，门户可接替其鉴权与文件服务，无需迁移课程计算后端。
